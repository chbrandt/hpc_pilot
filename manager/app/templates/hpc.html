ℹ What does this deploy?

Clicking Deploy to HPC runs a setup script on the remote HPC node via mccli (using your EGI Check-in token stored in this session). The script:

  1. Creates a virtualenv at ~/.pilot and installs supervisord (pip install supervisor) into it
  2. Downloads the wstunnel binary into ~/.pilot/bin/
  3. Writes a supervisord.conf that manages wstunnel (and the plugin) as supervised processes
  4. Installs the selected interLink plugin (echo, docker, or slurm)
  5. Starts supervisord, which in turn starts wstunnel and keeps it running

wstunnel connects to the server in your Kubernetes namespace, creating a WebSocket tunnel so that interLink can communicate with your HPC node.

The script is idempotent: re-running it will regenerate the config and restart services without breaking existing installations.
